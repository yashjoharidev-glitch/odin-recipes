# odin-recipes

`OdinRecipes` project is a practice project for understanding and practicing basic HTML tags and elements like `<p>`, `<a>`, `<img>` etc and the basic structure or the boilerplate of HTML.

In this project, we will make a basic website with a homepage ( `index.html` ) that will show various delicious dishes and links to recipes to those dishes. Once a recipe link is clicked, user will be taken to the Recipe page (like biryani.html or samosa.html).

## Features added
1. `index.html` in the parent directory
2. Created a `recipes` directory that contains following pages :-
    - `biryani.html` page
    - `friedrice.html` page
    - `samosa.html` page
3. All three pages contains an image, description of the dish, ingredients involved and steps required to make it.

## Things I learned
 - how to create html pages
 - how to add images using `<img>` tag
 - how to add hyperlinks using `<a>` tag and `href` attribute
 - how to use git commands like `git add`, `git commit`, `git status`, `git push origin main` etc
