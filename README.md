# odin-recipes

OdinRecipes project is a practice project for understanding and practicing basic HTML tags and elements like `<p>`, `<a>`, `<img>` etc and the basic structure or the boilerplate of HTML.

In this project, we will make a basic website with a homepage (index.html) that will show various delicious dishes and links to recipes to those dishes. Once a recipe link is clicked, user will be taken to the Recipe page (like biryani.html or samosa.html).
